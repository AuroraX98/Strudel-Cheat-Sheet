# Strudel Cheat Sheet

A plain-language Strudel reference with beginner, intermediate, and advanced lessons, a searchable sound catalog, and examples you can copy.

**Start with the HTML file for search and copying. Choose the PDF for reading or printing.** You make the actual music in [Strudel](https://strudel.cc/).

## What is included?

| File | What it gives you |
|---|---|
| `strudel-complete-reference.html` | A reference you can open in a browser, with search, filters, copy buttons, and sample filenames. It works offline after you download it. |
| `strudel-complete-reference.pdf` | A 226-page reference for reading, printing, and keeping beside your music code. |
| `SHA256SUMS.txt` | File fingerprints called checksums, for checking that the two reference files downloaded unchanged. |

The reference includes **576 command and command-family entries**, **1,654 default sound names**, and **218 optional sound collections**. Together, the default and optional lists contain **1,852 distinct names**. Some names appear in both lists.

## Learn one small thing at a time

- **Beginner:** Make a beat, learn the symbols inside quotes, play notes, and change the sound.
- **Intermediate:** Combine patterns, make song sections, use scales, load recordings, and add changing settings.
- **Advanced:** Explore sound design, unusual tunings, stepwise patterns, visual tools, controllers, other sound engines, and custom tools.

In the HTML, choose **Learning guide** to start. Use **Commands** to find a function, **Sounds** to find a sound name or sample filename, and **Word meanings** when a term is unfamiliar.

To hear an example, copy it into [strudel.cc](https://strudel.cc/), press **Play**, then press **Update** after a change. Examples using extra samples, hardware, or other tools explain the setup they need. The HTML reference itself does not play music. Its search and copy tools work without the internet; online source links need a connection.

## Date and scope

This edition was prepared on **3 October 2026** from the official documentation and deployed reference checked that day. It is a dated snapshot. Strudel can change, and your own samples, instruments, and custom functions can add more possibilities. Optional collections must be loaded before their sounds can play. This reference does not claim that every possible combination has been tested.

The guide draws on the [official Strudel documentation](https://strudel.cc/learn/getting-started/), its live reference and sound lists, and the [official source on Codeberg](https://codeberg.org/uzu/strudel). For the latest tools and loaded sounds, check Strudel’s own **Reference** and **Sounds** panels.
